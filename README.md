## ⚡ Key Features
<a id="key-features"></a>

### Core Functionality:
- **Customizable Capture Area** — Select a rectangular area with your mouse for precise captures.
- **Active Screen Capture** — Capture only the active window for focused documentation.
- **Full-Screen Capture** — Easily take a snapshot of your entire screen.
- **Mouse Pointer Options** — Choose to include or exclude the mouse pointer in your captures.
- **Capture Delay** — Set a delay before capturing to prepare your screen.

### Advanced Features:
- **Multiple Format Support** — Save your captures in JPEG, BMP, or GIF formats.
- **Naming Configuration** — Customize names for your saved images for easy organization.
